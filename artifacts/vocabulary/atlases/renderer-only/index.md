# GraphSCII renderer-only reference atlas

Renderer-only semantics are preserved without consuming additional PUA codepoints. Exact-reuse semantics are counted here but are not duplicated visually because their bitmap already has an encoded owner.

- Renderer-only semantic aliases: **3,392**
- Exact encoded reuse aliases: **414**
- Derived aliases: **2,978**
- Unique derived bitmaps shown: **2,555**
- Pages: **10**
- Ordering: deterministic bitmap-key order

Each shown renderer-only visual has a stable research ID (`R0000`, …), style/reason metadata, semantic aliases, optional Hamming-distance fallback metadata, and its exact 8×16 bitmap.
