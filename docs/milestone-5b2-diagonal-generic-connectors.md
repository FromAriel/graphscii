# Milestone 5B.2 — Deterministic Diagonal Generic Connector Basis

Status: **COMPLETE — FULL-CHAIN VERIFIED, UNALLOCATED**

Milestone 5B.2 finishes the generic connector selection with a deliberately simple diagonal rule system.

## 24 reasoned full-X rules

The canonical cell is 8×16. Rather than sampling arbitrary diagonal crossings, the diagonal family is generated by two axis-squash sweeps:

```text
16 vertical-squash rules  DV00..DV15
 8 horizontal-squash rules DH00..DH07
                           -----
                              24
```

A vertical level removes that many total rows from the X bounding box, divided as evenly as possible between top and bottom. A horizontal level does the same with columns from left and right. Each rule therefore has an exact integer span and a directly calculable slope.

The terminal single-row/single-column bar-like rules are generated rather than special-cased; exact reuse makes them free when they coincide with an existing straight graphic.

Each X consists of two opposite-corner Bresenham diagonals. Each diagonal is split at its raster midpoint into named legs `NW`, `NE`, `SE`, and `SW`. This makes removing one leg deterministic while preserving exact reconstruction of the full X.

## Exhaustive one-leg-removal measurement

Every one of the 24 full X rules was tested with all four possible missing legs:

```text
full-X semantics                      24
one-leg-removed semantics             96
raw measured diagonal semantics       120
valid connected semantics             120
unique exact diagonal raster owners   107
graphics-v0 exact reuse owners          2
orthogonal exact reuse owners           0
incremental novel owners              105
```

Keeping all 96 three-leg diagonal forms would therefore require 105 incremental diagonal owners overall and overflow the 60-slot post-orthogonal budget by 45.

## Final deterministic 60-semantic diagonal selection

All 24 full-X rules are retained.

For three-leg forms, the 16:8 cell dimensions imply a 2:1 vertical:horizontal sampling ratio. The selection therefore uses six evenly spread vertical squash levels and three evenly spread horizontal squash levels:

```text
DV00
DV03
DV06
DV08
DV11
DV14

DH02
DH04
DH06
```

Every selected angle rule keeps all four missing-leg orientations. This preserves quadrant/orientation symmetry and avoids any random or frequency-driven selection.

The resulting semantic basis is exactly:

```text
24 full-X semantics
36 three-leg semantics   (9 angles × 4 missing legs)
----------------------
60 diagonal semantics
```

Measured exact-dedup result:

```text

selected exact raster owners             59
existing graphics-v0 owners reused        2
new diagonal glyphs required             57

new orthogonal connector glyphs         544
new diagonal connector glyphs            57
                                       -----
final new connector glyphs              601
BMP PUA reserve                          604
reserve remaining                          3
```

## Final generic connector rule system

The selected connector language is now compact and explainable:

1. Orthogonal: all 128 `(x,y)` crossings, each with full `NESW` plus the four one-arm-removed masks.
2. Diagonal full X: all 24 axis-squash angle rules.
3. Diagonal three-leg: all four missing-leg orientations at the nine fixed 2:1-proportional angle samples above.

Exact bitmap dedup determines storage. The semantic rule remains richer than the physical glyph list.

No PUA codepoints are allocated by 5B.2 itself. A later registry/allocation slice can assign the measured 601 novel connector owners while retaining the final 3 reserve slots.
