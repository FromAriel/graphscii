# Milestone 2B — Straight-Line Class Catalog

Status: **implemented and locally verified**.

Milestone 2B adds the first generated human-readable shape-class publication to GraphSCII:

```text
artifacts/classes/straight-lines.md
```

The catalog is generated from the semantic manifest produced by Milestone 2A plus the canonical per-glyph ASCII artifacts produced by Milestone 1. It is never intended to be edited by hand.

From `geometric-glyph-lab/`:

```powershell
npm run generate
npm run verify
```

Specific commands:

```powershell
npm run generate:catalog
npm run verify:catalog
```

## Catalog contents

The current straight catalog contains exactly:

```text
visual glyph entries      746
mathematical aliases      832
canonical cell           8×16
allocation       U+00E000..U+00E2E9
allocation status  provisional
```

Every glyph entry includes:

- full six-digit Unicode codepoint,
- decimal and hexadecimal glyph ID,
- provisional allocation status,
- family membership,
- canonical bitmap key,
- alias count,
- connectivity semantics,
- every mathematical straight alias,
- source candidate ID for each alias,
- link to the canonical ASCII file,
- link to the canonical PNG file,
- the exact 16-row × 8-column ASCII bitmap inline.

Example alias notation:

```text
straight:L13>R4
```

The catalog preserves the Milestone 2A rule that aliases are alternative two-port interpretations of the same raster glyph. Ports from separate aliases must not be combined into an implied junction.

## Verification contract

`verify:catalog` does not merely count Markdown headings. It regenerates the entire expected catalog in memory from the semantic manifest and canonical ASCII artifacts, normalizes line endings, and requires byte-for-byte equality with `artifacts/classes/straight-lines.md`.

It additionally verifies:

- exactly 746 glyph headings,
- every manifest glyph has its expected heading,
- every one of the 832 alias keys appears,
- catalog statistics agree with `artifacts/manifest/stats.json`,
- catalog schema version is 1,
- the reported generated byte count matches the actual file.

A local reconstructed generation of the current vocabulary produced a 515,888-byte catalog and passed the full catalog verifier.

## Generation order

The complete `npm run generate` pipeline is now:

```text
Milestone 1 base artifacts
          ↓
Milestone 2A semantic registry
          ↓
Milestone 2B straight-lines.md
```

The full generated straight-line artifact tree will be deliberately snapshotted into Git during Milestone 2C rather than making every source-code commit automatically carry hundreds of generated files.
