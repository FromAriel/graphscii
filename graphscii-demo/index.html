The mouse chooses edge crossings; the crossings choose nodes. Every boundary node is snapped once, mated exactly into the adjacent cell, and rendered with the corresponding GraphSCII font glyph.

Slice 1 contract

The real pointer trajectory determines which cell edges are crossed. Each crossing snaps to the nearest node on that exact edge. The adjacent cell receives the exact mating L/R or T/B node; that crossing is never independently re-quantized.

Freehand, line, Bezier, and ellipse all use the same crossing compiler. Immediate cell backtracking is erased before glyphs are emitted. Every consecutive stored segment is required to share the exact same canonical node with the next segment.

Debug Export records the exact pointer/coalesced-event path, every raw boundary crossing, every final GraphSCII segment, continuity checks, and the complete glyph panel so a bad stroke can be reproduced and inspected directly.
